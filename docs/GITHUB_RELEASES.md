# GitHub Releases

GitHub Releases hosts the installers and update metadata.

## Required Repository Changes

The update provider and download site are configured for `HarshaTammana07/dailycheck`.
Set the two public Supabase repository variables described in `GITHUB_SETUP.md`.

## Artifacts

The release should contain:

- Windows x64 NSIS installer.
- macOS Apple Silicon DMG.
- macOS Intel DMG when supported.
- Update metadata generated by `electron-builder`.
- Release notes.

## Website Downloads

The Pages workflow queries the latest published GitHub Release and generates
`release.json` from actual uploaded assets. Each platform button remains disabled
until a matching artifact exists. Release publication explicitly dispatches Pages.
